每日简报 Windows 客户端
====================

1. 先把整个文件夹放到固定位置，例如 D:\Apps\NewsDigest，再双击 NewsDigest.exe。
   不要放在下载目录里运行后再移动，否则开机启动路径会失效。

2. 双击后如果有已缓存的简报，会直接用浏览器打开；没有缓存时会弹启动提示。
   随后程序常驻右下角托盘，平时不会弹主窗口；有新一期时会弹系统通知。
   首次运行会自动写入当前用户的“开机启动”，不需要管理员权限。

3. GitHub Actions 每天北京时间 10:30 生成日报并发布 latest.json。
   客户端每 5 分钟检查一次，有新一期就弹 Windows 通知。
   如果 10:30 时电脑关机，下次开机运行客户端时会补弹最近一期。

4. 点击通知，或右键托盘图标选择“打开今日简报”，会用默认浏览器打开完整页面。
   页面包含今日要点、为你推荐、海外要闻、微博、X、GitHub、Meta、中文热榜等板块，
   每条都保留原始链接。

5. 托盘菜单：
   - 打开今日简报
   - 立即检查更新
   - 开机启动（可勾选/取消）
   - 打开配置目录
   - 退出

6. 首次运行 Windows 可能提示“已保护你的电脑”（SmartScreen），
   因为 EXE 没有购买代码签名证书。选择“更多信息 → 仍要运行”即可。
   程序不收集任何个人数据，只读取公开的 latest.json。

7. 配置文件位置：%APPDATA%\NewsDigest\config.json
   可以修改：
   - feed_urls：订阅地址列表，按顺序回退
   - poll_seconds：检查间隔，最小 60 秒

8. 如果 GitHub Raw 访问不稳定，客户端会自动尝试 jsDelivr。
   也可以把 feed_urls 改成自己的镜像地址。

9. 支持 Windows 10/11 64 位。无需安装 Python、Node.js 或 .NET。
